Introduction

This guide is for my own learning purposes and not intended for public consumption.


With this documentation I aim to provide myself with a quick guide I can refer to when implementing my .css files on sites external to my normal development environment. I will attempt to write tidy and consumable documentation and while I'm at it I may look to create and constantly improve a CRUD app to link into the rest of my ecosystem.


Getting Started

I host my CSS on the sub-domain here: https://css.remeil.co.nz/rem.css. Here is the starting boilerplate:

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <link rel="apple-touch-icon" sizes="180x180" href="https://remeil.co.nz/apple-touch-icon.png">
    <link rel="icon" type="image/png" sizes="32x32" href="https://remeil.co.nz/favicon-32x32.png">
    <link rel="icon" type="image/png" sizes="16x16" href="https://remeil.co.nz/favicon-16x16.png">
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Nunito+Sans:ital,opsz,wght@0,6..12,200..1000;1,6..12,200..1000&display=swap" rel="stylesheet">
    <link rel="stylesheet" href="https://css.remeil.co.nz/rem.css">
    <title>Remeil's New Page Template</title>
  </head>
  <body>
    <div class="container">
      <div class="row">
        <div class="col-sm-12"></div>
      </div>
    </div>
  </body>
</html>

Breakpoints

Designed with a mobile-first focus across 5 distinct breakpoints. Anything smaller than 396px spans 1 column at 100% width.

Name Class prefix Breakpoint
Extra Small none <396px
Small col-sm- ≥396px
Medium col-md- ≥600px
Large col-lg- ≥900px
Extra Large col-xl- ≥1200px
